# Website Pemuda-Pemudi RT

Website statis untuk organisasi pemuda-pemudi RT.

## File
- `index.html` — struktur halaman
- `style.css` — desain/responsif
- `script.js` — menu mobile dan form aspirasi demo

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload ketiga file ini ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save, lalu tunggu GitHub Pages membuat alamat website.

Semua data pada website ini masih contoh dan bisa diganti sesuai nama RT, pengurus, kegiatan, kontak, dan foto asli.
